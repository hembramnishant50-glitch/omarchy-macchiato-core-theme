## 🧠 Philosophy

<div align="center">

**Macchiato Core for Quattro** — sharp, high-contrast, and instant.

*Pure solid hex + 12px rounding + frosted blur + smooth `easeOutQuint` — no transparency tricks.*

</div>

> Built for speed. Every surface is a solid `#1e2030` mantle. Active states pop with `#c6a0f6` Mauve. Inactive rests on `#939ab7` Overlay2. No muddy purples, no Mocha bleed.

## 🎨 Icons & Cursors — System Theming

<div align="center">

*Complete the look — Papirus Dark Violet + Catppuccin Mauve*

</div>

```bash
# 1. Papirus Dark — Violet folders
yay -S papirus-icon-theme papirus-folders-git
papirus-folders -C violet --theme Papirus-Dark
gsettings set org.gnome.desktop.interface icon-theme 'Papirus-Dark'

# 2. Catppuccin Mauve cursors
yay -S catppuccin-cursors-mocha
gsettings set org.gnome.desktop.interface cursor-theme 'Catppuccin-Mocha-Mauve-Cursors'
```

## 🔧 Customization

<details>
<summary><b>Change background or border?</b></summary>

Edit `colors.toml`:
```toml
background = "#1e2030"              # mantle
hyprland_active_border = "#c6a0f6"  # mauve
hyprland_inactive_border = "#939ab7" # overlay2
```
Then `omarchy-theme-set macchiato-core`.

</details>

<details>
<summary><b>Ghostty padding error?</b></summary>

`padding = 8` is deprecated → use:
```ini
window-padding-x = 8
window-padding-y = 8
```
Fixed in this theme.

</details>
